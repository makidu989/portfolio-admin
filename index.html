Firebase 연결 설정 필요

이 파일의 firebaseConfig에 Firebase 콘솔의 웹 앱 설정 정보를 입력해 주세요. 비밀번호나 서비스 계정 키를 입력하지 마세요.

관리자 로그인

Firebase Authentication에 등록한 이메일/비밀번호로 로그인하세요. 관리 권한은 Firestore 규칙에서 별도로 확인합니다.

기본 프로필

프로젝트 편집

한 줄에 하나씩 프로젝트명 | 설명 | 이미지 경로 형식으로 입력하세요. 이미지 경로는 기존 GitHub에 업로드된 파일 경로 또는 HTTPS 주소만 사용하세요.

기존 V5 프로젝트는 자동으로 가져오지 않습니다. 아직 기존 페이지와 데이터 연결 전입니다.

전체 콘텐츠 편집

원본 V5의 경력·학력·자격·PDF·인포그래픽·외부 링크까지 편집합니다. 항목은 한 줄에 하나씩 작성하며, 각 줄은 | 로 구분합니다. 자료 파일은 기존 사이트에 보관됩니다.

이미지와 PDF는 업로드가 아닌 기존 경로·주소 편집 방식입니다. 기존 이미지 파일 자체는 교체하지 않습니다.

미리보기

입력값이 즉시 아래에 표시됩니다. 저장 전에도 확인할 수 있습니다.

기존 V5 내용 가져오기

원본 ZIP에서 확인한 소개·역량·프로젝트 정보를 편집란으로 가져옵니다. 현재 초안의 입력값은 교체되지만, ‘초안 저장’을 누르기 전에는 Firebase 데이터가 바뀌지 않습니다. 기존 인포그래픽과 PDF는 공개 사이트에서 그대로 유지됩니다.

저장 / 게시

초안 저장은 관리자에게만 보이고, 게시하기는 published/site 문서를 갱신합니다. 기존 공개 페이지가 이 문서를 읽도록 연결되기 전에는 방문자 화면은 바뀌지 않습니다.
